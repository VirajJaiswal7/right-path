# Right Path Initiative

A warm, modern nonprofit website for Right Path Initiative. The site communicates the organization's mission, programs, impact, stories, and ways to support children and communities across Uganda.

## Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Lucide React icons
- Wouter routing

## Local development

This repository contains the complete frontend source under src/.

```bash
pnpm install
pnpm run dev
```

## Production build

```bash
pnpm run build
```

The donation, contact, and newsletter forms are frontend-only demos until an approved email or payment provider is connected. Official contact details, photography, staff, partner logos, and payment details remain placeholders by design.
